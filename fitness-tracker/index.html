Set up the Shortcut (one time, ~10 min)

First, in Hevy: Profile → Settings → Integrations → Apple Health → on. Hevy then writes each workout to Health (type, duration, calories). Sets and reps stay in Hevy.

Then in the Shortcuts app: tap +, name it Rebirth Sync, and add these actions in order:

  1. Find Health Samples → Type: Steps, filter Start Date is today.
  2. Calculate Statistics → Sum of the samples. Long-press the result and rename the variable Steps.
  3. Find Health Samples → Type: Weight, Start Date is today, Sort by Start Date, Latest First, Limit 1. Rename to Weight.
  4. Find Health Samples → Type: Workouts, Start Date is today.
  5. Repeat with Each item in those workouts. Inside it, add a Text action: 
    workout: [Repeat Item › Type] | [Repeat Item › Duration] | [Repeat Item › Source]
    Tap the Repeat Item variable to pick each property. If your iOS names them differently, the closest match works.
  6. After the repeat, add Format Date → Current Date, Custom format yyyy-MM-dd.
  7. Add a Text action, exactly like this, inserting the variables: 
    REBIRTH SYNC
date: [Formatted Date]
steps: [Steps]
weight: [Weight]
[Repeat Results]
  8. Copy to Clipboard (the Text).
  9. Optional: Open URLs with this app's link, so it opens ready to paste.

Make it automatic: Shortcuts → Automation → + → Time of Day, 9:30 pm, Daily, Run Immediately → Run Shortcut “Rebirth Sync”. Then open the app and paste.

The first run asks for Health permission. Allow Steps, Weight and Workouts. Blank values are skipped, so a day with no weigh-in is fine.
