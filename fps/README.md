# Neon Arena

A wave-survival first-person shooter that runs in the browser. One HTML file, no build step; Three.js loads from cdnjs.

**Play:** open `index.html` in a desktop browser (Chrome, Firefox, Edge, Safari) and click to start.

| Key | Action |
| --- | --- |
| Mouse | Look |
| WASD / arrows | Move |
| Shift | Sprint |
| Space | Jump (you can land on crates and cover walls) |
| Left click | Fire (hold for full auto) |
| R | Reload |
| Esc | Pause |

## How it plays

- Hostile drones spawn in waves from the arena edges. Each wave brings more of them, and they get faster, shoot more often and aim better.
- From wave 3, larger magenta "heavy" drones show up: more health, harder hits.
- Drones close in when they can't see you, hold mid-range and strafe when they can, and fire glowing projectiles you can dodge or block with cover.
- Headshots do double damage. Drones sometimes drop health (green cross) or ammo (yellow box).
- Clearing a wave restores some health and ammo and adds a score bonus. Your best score is saved in the browser.

Requires a mouse and keyboard (it uses Pointer Lock); there are no touch controls.
